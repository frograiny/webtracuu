🚀 Hướng Dẫn Khởi Chạy Dự Án

Chạy toàn bộ hệ thống VNU Research API chỉ với 1 dòng lệnh (Dùng Docker)

Yêu cầu bắt buộc: Máy tính của bạn cần phải được cài đặt Git và Docker Desktop (nhớ mở Docker Desktop lên cho nó chạy ngầm nhé).

1 Tải mã nguồn về máy

Mở Terminal (Command Prompt hoặc PowerShell) và chạy lệnh sau để clone project về:

git clone <link_github_cua_project>
cd webtruong

(Nhớ thay <link_github_cua_project> bằng link repo Github thực tế).

2 Khởi động hệ thống (Magic Button 🪄)

Để dựng lên toàn bộ hệ thống bao gồm: Backend API (FastAPI), Cơ sở dữ liệu (PostgreSQL), Redis Cache, bạn chỉ cần gõ đúng 1 dòng lệnh duy nhất:

docker-compose up -d --build
Ngồi nhâm nhi tách trà (khoảng 2-3 phút) ☕
Ở lần chạy đầu tiên, Docker sẽ tải các file cài đặt môi trường. Không cần làm gì thêm, hệ thống sẽ tự động tạo Database, tự động tạo các bảng và tự động chèn dữ liệu mẫu (Auto-seed) cho bạn.

3 Kiểm tra thành quả! 🎉

Mở trình duyệt web của bạn lên (Chrome/Edge/Brave) và dán đường link sau vào thanh địa chỉ để test thử API tìm kiếm (Giống y hệt hình ảnh minh hoạ):

http://localhost:8000/api/v1/projects/search?q=Nguyễn%20Văn&limit=10

Nếu bạn thấy kết quả trả về một đoạn dữ liệu JSON giống thế này, xin chúc mừng, hệ thống đã chạy hoàn hảo! 🥳

{ "status": "success", "data": { "total": 2, "items": [ { "id": "NCKH-2023-001", "tenDeTai": "Ứng dụng trí tuệ nhân tạo...", "chuNhiem": "Nguyễn Văn An", "doiTuong": "Giảng viên" ... } ] } }

4 Khám phá thêm

Hệ thống còn đi kèm các tiện ích siêu xịn khác:

  • Swagger UI (Tài liệu API): http://localhost:8000/docs
  • Web Frontend (nếu có): http://localhost:5173
  • Grafana (Biểu đồ giám sát): http://localhost:3000 (Tài khoản: admin/admin)

Để tắt hệ thống, mở Terminal ở thư mục dự án và gõ: docker-compose down
