Chiến lược Index

GIN
search_vector
Inverted Index — ánh xạ mỗi từ → danh sách hàng chứa nó. Tốc độ O(log N)
Cực nhanh
GIN + trgm
ten_de_tai
Trigram Index — hỗ trợ tìm kiếm mờ, sai chính tả, thiếu dấu
Rất nhanh
B-Tree
nam_thuc_hien, trang_thai
Lọc nhanh theo năm, trạng thái — dùng khi kết hợp filter
Nhanh

TSVECTOR hoạt động thế nào?

1
Dữ liệu gốc
"Nghiên cứu ứng dụng trí tuệ nhân tạo trong giáo dục"
→
2
Lexer phân tách + bỏ dấu
'nghien''cuu''ung''dung''tri''tue''nhan''tao''giao''duc'
→
3
GIN Index lookup
Tìm thấy trong O(log N) thay vì quét toàn bảng O(N)

Thuật Toán Tìm Kiếm

Thử nhập từ khóa bên dưới để xem luồng xử lý thực tế

Nhập từ khóa và nhấn "Tìm kiếm" để xem luồng xử lý
👤
User nhập
"Tri tue nhan tao"
🔧
Normalize
Lowercase, xóa trắng thừa, bỏ dấu tiếng Việt, thay từ đồng nghĩa
⚡
Redis Cache
Kiểm tra key search_cache:q:tri+tue+nhan+tao
✅ Cache Hit~2ms
❌ Cache Miss↓
🗄️
PostgreSQL FTS
WHERE search_vector @@ to_tsquery('...')
+ similarity() cho fuzzy matching
📊
Ranking
A Title (cao nhất)
B Author
C Abstract
Score = ts_rank × 2.0 + max_similarity
✨
Response
JSON + lưu cache Redis (TTL 5 phút) → ~50ms

Cache Invalidation (Xóa cache cũ)

✏️
Admin sửa/xóa đề tài
→
💾
DB commit thành công
→
🧹
Background Task xóa tất cả key search_cache:*
→
🔄
Lần search tiếp → Cache Miss → Lấy data mới

Xác Thực & Bảo Mật

Click vào từng bước để xem chi tiết

1. Login
Click để mở rộng ↓
Access TokenTTL: 60 phútGửi trong Header mỗi API call
Refresh TokenTTL: 7 ngàyChỉ dùng để lấy Access mới
2. Gọi API (mỗi request)
Click để mở rộng ↓
Authorization: Bearer <access_token>
Middleware kiểm tra: Token hợp lệ? Chưa hết hạn? JTI có trong Blacklist?
3. Token hết hạn → Auto refresh
Click để mở rộng ↓
Frontend dùng Refresh Token gọi /auth/refresh → nhận Access Token mới → user không bị logout
4. Logout → Redis Blacklist
Click để mở rộng ↓
Lấy JTI (JWT ID) → thêm vào Redis Blacklist với TTL = thời gian còn lại
SETEX blacklist:<jti> <remaining_seconds> 1

Rate Limiting (Chống DDoS)

🔑
Authenticated User
Key = user_id từ JWT
100 req/phút
👤
Guest (không login)
Key = Hash(IP + User-Agent)
30 req/phút
Phân biệt thiết bị cùng WiFi
