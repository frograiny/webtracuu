Tra cứu

Kiến trúc Hệ thống (3 Lớp & Nginx Gateway)

1

Nginx Gateway (Cổng 80)

Đón tất cả request. Nếu là API trỏ vào Backend (8000), nếu là trang thường trỏ vào Frontend (5173). Giúp vượt tường lửa trường học.

2

FastAPI Backend (Cổng 8000)

Xử lý nghiệp vụ logic, kiểm tra phân quyền JWT Token, băm bảo mật mật khẩu bằng Bcrypt.

3

PostgreSQL (Data) & Redis (Cache)

Postgres lưu trữ bền vững. Redis lưu cache tìm kiếm tạm thời để hệ thống load ngay tức thì dưới 10ms.

2 Luồng Nghiệp Vụ Quan Trọng Nhất

A. Đăng nhập & Phân quyền Admin

Luồng Xác thực JWT

  1. Admin gửi Email + Password lên Backend.
  2. Backend băm password đối chiếu qua thuật toán Bcrypt.
  3. Nếu đúng, Backend trả về chuỗi JWT Token bảo mật.
  4. Frontend lưu Token vào localStorage và tự động đính kèm vào Header ở mọi request sau.
  5. Backend giải mã Token để cho phép Admin thao tác sửa dữ liệu.
B. Sửa/Thêm đề tài & Xóa Cache

Luồng Invalidate Cache tự động

  1. Admin ấn **Thêm mới** / **Sửa** đề tài trên trang quản trị.
  2. Backend cập nhật dữ liệu mới vào PostgreSQL DB thành công.
  3. Backend tự động kích hoạt **Background Task** để dọn dẹp các cache tìm kiếm cũ trên Redis.
  4. Người dùng ngoài trang chủ thực hiện tìm kiếm ➡️ Redis nạp và trả về kết quả mới nhất.

Thuật Toán Tìm Kiếm Đề Tài (FTS + Fuzzy Search)

1. Xử lý Không dấu tiếng Việt (Unaccent)

Mọi văn bản tiếng Việt khi lưu và tìm kiếm đều được Backend chạy qua hàm immutable_unaccent để bỏ toàn bộ dấu tiếng Việt (ví dụ: chuyển "Nghiên cứu" thành "Nghien cuu"). Giúp người dùng gõ không dấu vẫn ra kết quả chuẩn xác.

2. Fuzzy Search (Chấp nhận sai chính tả)

Kích hoạt PostgreSQL extension pg_trgm để chia nhỏ từ thành các cụm 3 chữ cái. Hệ thống tính điểm tương đồng similarity() giữa từ khóa người dùng gõ và đề tài. Nếu tương đồng trên 20% thì vẫn hiển thị kết quả gợi ý.

5 Công thức tính điểm ưu tiên (Score)

Score = (ts_rank(search_vector, tsquery) * 2.0) + similarity(unaccent(title), unaccent(q))

* Ưu tiên tìm kiếm FTS theo từ tố (ts_rank) với trọng số Tiêu đề cao gấp đôi, cộng thêm điểm gần nghĩa của pg_trgm để đưa đề tài khớp nhất lên đầu.

Danh sách các API endpoints quan trọng

Phương thức Endpoint URL Phân quyền Chức năng

title, author, abstract

Tiêu đề, Tác giả và Tóm tắt nghiên cứu khoa học.
