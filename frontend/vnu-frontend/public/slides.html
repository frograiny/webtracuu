Phân tách từ tố tìm chính xác dựa trên tsvector

Công Thức Tính Điểm Tin Cậy (Score)
Score = (ts_rank * 2.0) + similarity 
SELECT title, 
  ts_rank(search_vector, to_tsquery('vietnamese', :q)) * 2.0 + 
  similarity(unaccent(title), unaccent(:raw_q)) AS score
FROM projects
WHERE search_vector @@ to_tsquery(...) 
   OR unaccent(title) % unaccent(:raw_q)
ORDER BY score DESC;

Cơ Sở Dữ Liệu & Cơ Chế Cache

PostgreSQL Index & Schema
  • GIN Index: Thiết lập chỉ mục GIN trên cột tổng hợp `search_vector` giúp tìm kiếm đạt tốc độ dưới 5 mili-giây.
  • Mối quan hệ chặt chẽ: Quản lý liên kết 1-nhiều và nhiều-nhiều giữa Đề tài, Tác giả, Đơn vị đào tạo qua SQLAlchemy.
Redis Cache Invalidation Flow
  • Bộ nhớ đệm: Redis lưu trữ toàn bộ danh sách kết quả tìm kiếm phổ biến và thông tin chi tiết đề tài.
  • Đồng bộ tức thì: Khi Admin thêm mới hoặc chỉnh sửa dữ liệu, một Background Task trong FastAPI lập tức quét và xóa (`DEL`) cache cũ của Redis để đảm bảo cập nhật dữ liệu trực tuyến.

SLIDE 06 / 08

Xác Thực & Bảo Mật Hệ Thống

JWT Dual Token

Sử dụng Access Token (60 phút) truyền qua Bearer Header và Refresh Token (7 ngày) lưu an toàn trong Cookie HttpOnly để chặn đứng tấn công XSS/CSRF.

Token Blacklisting

Khi người dùng đăng xuất, ID của Access Token cũ được đẩy vào Redis Blacklist với thời gian sống (TTL) bằng thời hạn còn lại của Token để ngăn chặn tái sử dụng trái phép.

Rate Limiting

Tích hợp thuật toán Sliding Window Log trên Redis, giới hạn tối đa 100 yêu cầu/phút đối với mỗi địa chỉ IP để chống phá hoại, spam API hoặc tấn công từ chối dịch vụ (DDoS).

Mô hình an ninh ba lớp: Xác thực, Đăng xuất an toàn và Giới hạn truy cập

DevOps, Vận Hành & Giám Sát

Đóng Gói Docker Compose

Hệ thống được ảo hóa hoàn chỉnh thành 6 vùng chứa (container) độc lập, tự động hóa toàn bộ quy trình khởi tạo qua 1 lệnh duy nhất: 

docker-compose up -d --build
Tự động vá lỗi (Auto-healing: restart always)
Giám Sát Hệ Thống
  • Prometheus: Thu thập thời gian thực các chỉ số phần cứng (CPU, RAM), số lượng kết nối DB và thời gian phản hồi của API.
  • Grafana Dashboard: Trực quan hóa dữ liệu hiệu năng, tự động cảnh báo khi có sự cố nghẽn mạng hoặc lỗi máy chủ.
